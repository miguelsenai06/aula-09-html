# Projeto HTML e CSS

Este projeto reúne exercícios práticos desenvolvidos com **HTML5 e CSS3**, abordando estilização, semântica, Flexbox, tabelas, vídeos e áudio.

## 📁 Arquivos do projeto

### 1. GameZone Retro

Arquivos:
- `05a_desafio.html`
- `05a_desafio.css`

Página de uma loja fictícia de jogos retrô chamada **GameZone Retro**.

Principais recursos:
- Título e subtítulo estilizados;
- Menu de navegação;
- Imagem de destaque;
- Lista de consoles;
- Tabela de preços;
- Efeitos visuais em estilo neon;
- Animação no título;
- Estilização com CSS externo.

## 2. Estrutura Semântica HTML5

Arquivos:
- `07_semantica.html`
- `07_semantica.css`

Página criada para demonstrar o uso correto de elementos semânticos do HTML5.

Principais recursos:
- `header`;
- `nav`;
- `main`;
- `section`;
- `article`;
- `aside`;
- `footer`;
- `address`;
- Layout organizado com Flexbox;
- Menu horizontal;
- Seções com cards e sombras.

## 3. Tabelas e Multimídia

Arquivos:
- `08_tab_multimidia.html`
- `08_tab_multimidia.css`

Página contendo uma tabela de relatório de vendas e elementos multimídia.

Principais recursos:
- Tabela com cabeçalho, corpo e rodapé;
- Valores alinhados e destacados;
- Vídeo local em HTML5;
- Vídeo incorporado do YouTube;
- Player de áudio;
- Estilização personalizada;
- Responsividade para dispositivos menores.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- Flexbox
- Tabelas HTML
- Vídeo HTML5
- Áudio HTML5
- Responsividade com `@media`

## ▶️ Como executar

1. Baixe todos os arquivos do projeto.
2. Coloque os arquivos HTML e CSS na mesma pasta.
3. Crie uma pasta chamada `assets`.
4. Coloque as imagens, vídeo e áudio utilizados dentro da pasta `assets`.
5. Abra a pasta no Visual Studio Code.
6. Abra qualquer arquivo `.html` no navegador.

Também é possível utilizar a extensão **Live Server** do VS Code para visualizar as páginas.

## 🎯 Objetivo

O objetivo deste projeto é praticar conceitos fundamentais de desenvolvimento web, incluindo:

- Estruturação de páginas com HTML5;
- Utilização de tags semânticas;
- Aplicação de estilos com CSS externo;
- Organização de layouts;
- Criação e estilização de tabelas;
- Uso de elementos de áudio e vídeo;
- Criação de páginas responsivas.
